# fixtures —— 可入仓的脱敏小样本

这里的样本**会进版本库**，用来在 CI 和换机器时也能跑通回归；体量大的真实样本走样本库（见上级 `README.md`）。

## 收录标准

- 单份 < 2 MB，能在一两秒内处理完；
- 已脱敏：公司名、项目名、人名、电话、金额、内部系统截图全部替换为「示例」「某某」「000」一类占位；
- 一个样本只针对一个考点，不要复刻整份业务文件。

## 结构

```
fixtures/
└─ <考点名>/
   ├─ input.<ext>
   └─ README.md      # 这组样本考什么、断言看哪几项
```

一组样本同时用于 `manifest.json` 里的某条用例时，把该用例的 `input` 直接指向 `fixtures/...` 也可以——此时样本在仓库内，`config.local.json` 与数据根对它不起作用，换机器照样能跑。
