# setup-test-case 本机配置（示例模板）

> 这是**模板**，不含任何本机信息。首次运行 setup-test-case 时，把它复制为同目录下的 `config.md` 再填写。
>
> `config.md` 记录**本机所有项目**共用的测试用例存放约定；它已列入仓库 `.gitignore`，不会提交。

## 全局约定

- **全局根目录**：`<绝对路径，例如 /Users/you/test-case-data 或 D:/sync/test-case-data>`
- **存储方式**：`本地盘` / `同步盘` / `网络盘`（同步盘意味着多机可见，网络盘需要在线才能跑）
- **分层模板**：`<root>/<owner>/<project>`（有多个 git 账号时用），或 `<root>/<project>`（单账号）
- **用例 id 命名**：`kebab-case`，与样本目录同名
- **入库策略**：样本与产物一律不进 git，仓库只留清单、断言、脱敏小样本
- **单份样本上限**：`200 MB`（超出建议先裁剪最小可复现片段）

## 已归档项目

每个项目建一次骨架就登记一行，便于下次直接复用路径、避免重复询问。

| 项目 | slug | 样本库路径 | 登记日期 | 备注 |
| --- | --- | --- | --- | --- |
| （示例）my-app | my-app | `<root>/me/my-app` | 2026-01-01 | 同步盘，多机可见 |

## 备注

- 全局根目录换位置时，只需改这一处；各项目的 `test-case/config.local.json` 各自指向自己那层。
- 若某项目要偏离全局约定（例如样本必须放内网盘），在该项目那一行的「备注」里写清例外原因。
